OpenClaw update failure: managed-service-preflight

managed-service-preflight: 34 reports, 21 still open

What it means: The updater refused before swapping packages because a check on the managed Gateway service failed.

What to do: 2026.9.4 updaters can refuse here before the target code ever runs. The fix is to use the manual procedure with the same package manager and prefix. On macOS, if /update or update.run failed with "running inside the gateway process tree", run openclaw update once from a separate Terminal.

The OpenClaw maintainer answered similar reports: #166206, #153990, #153729, #153547. These replies usually list exactly what to collect and the known fix for your version.

Stuck on 2026.9.3 or 2026.9.4? The OpenClaw maintainer's own recipe (#165706) is one manual hop to the current release, then a Doctor pass: npm install -g openclaw@2026.9.8 --allow-scripts=openclaw, then openclaw doctor --fix, then openclaw gateway restart. From 2026.9.8 onward, openclaw update handles the rest. On npm 11.15 or older, drop --allow-scripts=openclaw. Back up first with openclaw backup create --verify.

Before you retry, openclaw update status --json shows the unredacted failing step on your machine, and openclaw gateway status --deep shows what is actually serving. A retry overwrites that history.
